# homebrew-tenue

Homebrew tap для **tenué** — личного менеджера секретов для macOS.
Код закрытый, бинари раздаёт `tenue.moverq.dev`.

```sh
brew tap moverq1337/tenue
brew install --cask tenue          # приложение
brew install moverq1337/tenue/tenue-cli   # команда tenue для терминала
```

Приложение при первом запуске спросит лицензионный ключ — его выдаёт
владелец. Сайт и цена: https://tenue.moverq.dev

Нужен Mac на Apple Silicon и macOS 15 или новее. Сборки под Intel нет.
